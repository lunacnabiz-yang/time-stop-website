# 시간정류장 홈페이지

루나씨앤에이의 시간정류장 제품 소개 홈페이지입니다.

## 구성
- index.html: 홈페이지 내용
- style.css: 화면 디자인과 휴대폰 배치
- app.js: 메뉴와 이용 안내 동작
- morphs.js: 나이 변화 연출
- assets/: 제공된 제품·브랜드 이미지와 연출 자료

## 실행
별도 설치나 빌드 없이 실행합니다. GitHub Pages의 main 브랜치 최상위 폴더를 게시 위치로 선택합니다.

## 안내
인물과 나이 변화는 인공지능 연출 예시입니다. 문의 양식은 입력 내용을 파일로 저장하며 서버로 전송하지 않습니다.

이미지·영상·로고의 사용 권리는 원 권리자에게 있습니다.
